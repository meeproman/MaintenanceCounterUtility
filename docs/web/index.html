ยืนยันก่อนรีเซ็ตตัวนับซับหมึก (Mandatory Pre-Reset Check)

    
โปรดตรวจสอบและทำความเข้าใจทั้ง 8 ข้อก่อนดำเนินการรีเซ็ต:

1. การรีเซ็ตด้วยซอฟต์แวร์นี้เป็นการล้างเฉพาะตัวนับในหน่วยความจำเท่านั้น
2. ซอฟต์แวร์นี้ไม่ได้ทำความสะอาด เททิ้ง ซ่อมแซม หรือเปลี่ยนแผ่นซับหมึกจริง
3. คุณต้องตรวจสอบ ทำความสะอาด เปลี่ยนแผ่นซับหมึก หรือติดตั้งถังหมึกทิ้งภายนอกให้เรียบร้อยก่อนดำเนินการต่อ
4. การใช้งานอย่างไม่ถูกต้องอาจทำให้หมึกล้น รั่วซึม หรือเกิดความเสียหายต่อเครื่องพิมพ์ได้
5. ใช้สำหรับการบำรุงรักษาเครื่องของตนเองอย่างสมเหตุสมผลเท่านั้น
6. ไม่ควรรีเซ็ตตัวนับที่ยังอยู่ในระดับต่ำโดยไม่มีเหตุผลในการซ่อมบำรุงจริง
7. ระบบจะทำการสำรองข้อมูล EEPROM (ดาวน์โหลดไฟล์ .json) ให้อัตโนมัติก่อนเขียนค่าใหม่
8. เครื่องมือนี้ไม่มีส่วนเกี่ยวข้องกับบริษัท Epson
